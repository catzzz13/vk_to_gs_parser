# VK Parser — Полное руководство

> [!NOTE]
> **Что это за программа и как она работает?**
> Это умный парсер, созданный для автоматизации проверки заданий. Программа заходит в указанную вами группу ВКонтакте, находит темы (обсуждения), связанные с вашей командой, скачивает оттуда все комментарии, очищает их от мусора и красиво раскладывает в Excel-файл и/или Google-таблицу.
> 
> **Особенности кода:**
> - Программа защищена от блокировок со стороны ВКонтакте (встроен «умный лимитер» запросов).
> - Кэширует имена пользователей: если запустить её дважды за сутки, она не будет тратить время на повторную загрузку имен из VK.
> - В консоли при запуске отображается имя автора программы.

## 1. Настройка VK API (Токен)
Чтобы программа могла читать комментарии, ей нужен цифровой пропуск — **Токен**.

### Как получить токен?
1. Зайдите на сайт [vkhost.github.io](https://vkhost.github.io/).
2. Выберите приложение **Kate Mobile**.
3. Нажмите «Получить токен». Вас перекинет на сайт ВК, где нужно разрешить доступ. *Важно: программа запрашивает права `wall`, `groups`, `offline`. Право `offline` обязательно, иначе токен сгорит через час.*
4. После авторизации скопируйте длинную строку из адресной строки браузера (она начинается с `vk1.a...`).

### Куда его вставить?
Откройте файл `vk-parser/token.txt` (блокнотом) и вставьте токен туда. Удалите все лишние символы и комментарии, чтобы в файле осталась **только одна строка с токеном**.

## 2. Настройка Google Sheets (Опционально)
Если вы хотите, чтобы данные сами падали в гугл-таблицу, нужно создать «робота» (Сервисный аккаунт).

### Создание робота в Google Cloud
1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/) и создайте проект.
2. В разделе «Библиотека» (Library) найдите и включите **Google Sheets API** и **Google Drive API**.
3. В разделе «IAM & Admin» -> «Service Accounts» создайте аккаунт.
4. В этом аккаунте нажмите «Manage Keys» -> «Create new key» -> выберите **JSON**. Скачается файл.
5. Переименуйте этот файл в `credentials.json` и положите в папку `vk-parser` (заменив шаблон).

> [!IMPORTANT]
> **Самое важное! Не пропустите!**
> 1. Откройте ваш `credentials.json` и найдите адрес в поле `"client_email"`. Скопируйте его.
> 2. Откройте вашу Google-таблицу и нажмите кнопку **«Поделиться»**.
> 3. Вставьте скопированный адрес робота и дайте ему права **«Редактор»**. Без этого программа не сможет записать данные.

## 3. Настройка конфигурации (settings.json)
Файл `settings.json` — это мозг программы. Откройте его блокнотом.

```json
{
  "group_id": 233578280,
  "team_name": "Канониры Пеликана",
  "spreadsheet": "Моя таблица",
  "worksheet": "Лист1",
  "credentials": "credentials.json",
  "output": "output",
  "max_comments_per_topic": 10000,
  "requests_per_second": 3
}
```

*   `group_id`: ID группы ВК (только цифры).
*   `team_name`: Название вашей команды. Программа ищет темы, где есть слово «задание» и это название.
*   `spreadsheet`: Точное название Google-таблицы (без ссылок, просто имя).
*   `worksheet`: Название листа внутри этой таблицы (например, «Лист1»).
*   `requests_per_second`: Скорость. Лимит ВК — 3 запроса в секунду. Оставьте `3`.

## 4. Расшифровка пометок и логика фильтрации
Программа не просто копирует всё подряд, а анализирует текст.
*   **Игнорирование мусора:** Комментарии от сообществ (не людей) и пустые сообщения не попадают в итоговую таблицу.

> [!WARNING]  
> **Метка «ВРЕМЯ»**
> Если человек в комментарии кидает ссылку на пост (вида `vk.com/wall-123_456`), программа проверяет дату этого поста. Если комментарий написан **позже, чем через 36 часов** после публикации поста, в начало текста добавляется метка `ВРЕМЯ`.
> *Зачем:* Вы сразу видите, кто сдал задание с опозданием.

> [!WARNING]  
> **Метка «ЧИТОР»**
> Программа сравнивает текст комментариев в рамках одного задания. Если кто-то скопировал чужой ответ (текст совпадает на 100% без учета регистра), в начало добавляется метка `ЧИТОР`.
> *Зачем:* Мгновенное выявление списанных ответов.

## 5. Структура выгрузки (Excel и Sheets)

### Excel
Файл создается в папке `output` и называется `НазваниеГруппы_Дата.xlsx`. Каждое задание — это отдельный лист (вкладка). Колонки:
*   **A: ID** — ID пользователя.
*   **B: Упоминание** — тег `[id123|Имя]`.
*   **C: Имя** — имя и фамилия.
*   **D: Профиль** — ссылка на страницу.
*   **E: Комментарий** — текст (с метками «ВРЕМЯ» или «ЧИТОР»).
*   **F: Время** — дата и время отправки.

### Google Sheets
Данные пишутся в виде блоков, начиная с колонки **D** (первая строка зарезервирована под заголовки):
*   Колонки D, F, H и т.д. — ссылки на профили.
*   Колонки E, G, I и т.д. — тексты комментариев.
*   Задания автоматически сортируются по номеру (программа ищет слово «Задание N»).

## 7. Решение частых проблем

> [!CAUTION]
> **Ошибка: `Sheets подключение: Таблица '' не найдена`**
> **Решение:** Проверьте, что в `settings.json` в поле `spreadsheet` написано точное имя таблицы, и вы дали права «Редактор» роботу из `credentials.json`.

> [!CAUTION]
> **Ошибка: `VK API error [5]: User authorization failed`**
> **Решение:** Токен в `token.txt` неверный или устарел. Сгенерируйте новый (обязательно с правами `offline`).

> [!CAUTION]
> **Ошибка: `VK API error [6]: Too many requests per second`**
> **Решение:** Вы превысили лимит запросов ВК. Программа сама подождет и продолжит работу, но чтобы этого не было, убедитесь, что в `settings.json` стоит `"requests_per_second": 3`.

> [!NOTE]
> **Программа «зависла» и ничего не пишет в консоль**
> **Причина:** Она проверяет ссылки на посты для метки «ВРЕМЯ». Если в комментариях сотни ссылок, это требует много запросов. Просто подождите 1–2 минуты, она справится. *(Мы уже убрали искусственные паузы в коде, поэтому это происходит только при огромном количестве уникальных ссылок на посты).*
