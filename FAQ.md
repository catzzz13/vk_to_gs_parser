# VK Parser — Полное руководство

> [!NOTE]
> **Что это за программа?**
> Это умный парсер, который создан для автоматизации проверки заданий. Программа заходит в указанную вами группу ВКонтакте, находит темы (обсуждения), связанные с вашей командой, скачивает оттуда все комментарии, очищает их от мусора и красиво раскладывает в Excel-файл и/или Google-таблицу.

## 1. Настройка VK API (Токен)
Чтобы программа могла читать комментарии, ей нужен цифровой пропуск — **Токен**.

### Как получить токен?
1. Зайдите на сайт [vkhost.github.io](https://vkhost.github.io/).
2. Выберите приложение **Kate Mobile**.
3. Нажмите «Получить токен». Вас перекинет на сайт ВК, где нужно разрешить доступ. *Важно: программа запрашивает права `wall`, `groups`, `offline`. Право `offline` обязательно, иначе токен сгорит через час.*
4. После авторизации скопируйте длинную строку из адресной строки браузера (она начинается с `vk1.a...`).

### Куда его вставить?
Откройте файл `vk-parser/token.txt` (блокнотом) и вставьте токен туда. Удалите все лишние символы и комментарии, чтобы в файле осталась **только одна строка с токеном**.

## 2. Настройка Google Sheets (Опционально)
Если вы хотите, чтобы данные сами падали в гугл-таблицу, нужно создать «робота» (Сервисный аккаунт).

1. Зайдите в [Google Cloud Console](https://console.cloud.google.com/) и создайте проект.
2. В разделе «Библиотека» (Library) найдите и включите **Google Sheets API** и **Google Drive API**.
3. В разделе «IAM & Admin» -> «Service Accounts» создайте аккаунт.
4. В этом аккаунте нажмите «Manage Keys» -> «Create new key» -> выберите **JSON**. Скачается файл.
5. Переименуйте этот файл в `credentials.json` и положите в папку `vk-parser` (заменив шаблон).

> [!IMPORTANT]
> **Самое важное! Не пропустите!**
> 1. Откройте ваш `credentials.json` и найдите адрес в поле `"client_email"`. Скопируйте его.
> 2. Откройте вашу Google-таблицу и нажмите кнопку **«Поделиться»**.
> 3. Вставьте скопированный адрес робота и дайте ему права **«Редактор»**. Без этого программа не сможет записать данные.

## 3. Настройка конфигурации (settings.json)
Файл `settings.json` — это мозг программы. Откройте его блокнотом.

```json
{
  "group_id": 233578280,

  "spreadsheet": "Моя таблица",
  "worksheet": "Лист1",
  "credentials": "credentials.json",
  "output": "output",
  "max_comments_per_topic": 10000,
  "requests_per_second": 3
