# VK Parser 🤖

Быстрый и надежный парсер ВКонтакте (VK), созданный для автоматизации проверки и оценки заданий. Приложение ищет определенные темы в группе ВК, извлекает комментарии, применяет умную фильтрацию (выявляет опоздания и списанные ответы) и экспортирует обработанные данные в Excel и Google Таблицы.

**Автор:** [baunchik](https://vk.ru/baunchik)

## 🚀 Возможности
- **Умная фильтрация тем:** Автоматически находит темы, содержащие слово «задание» и название вашей конкретной команды.
- **Автоматические пометки:** 
  - `ВРЕМЯ` (LATE): Автоматически помечает комментарии, отправленные более чем через 36 часов после публикации поста по ссылке.
  - `ЧИТОР` (CHEATER): Выявляет и помечает дубликаты (скопированные) ответы.
- **Экспорт данных:**
  - **Excel:** Создает файл `.xlsx` с отдельным листом для каждого задания.
  - **Google Sheets:** Автоматически отправляет данные в указанную Google Таблицу.
- **Оптимизация производительности:** Написан на Rust с использованием асинхронных запросов, ограничения частоты (rate-limiting) и кэширования пользователей (для экономии лимитов VK API).
- **Простой установщик:** Скрипт на Python, который автоматически настраивает всё окружение Rust и компилирует релизную сборку.
