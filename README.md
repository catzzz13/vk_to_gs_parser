# VK Parser 🤖

Универсальный парсер комментариев ВКонтакте для проверки заданий с выгрузкой в Excel и Google Sheets.

**Автор:** [baunchik](https://vk.ru/baunchik)

## 🚀 Возможности
- Автоматический поиск нужных тем (по названию команды).
- Выгрузка данных в красивый Excel-файл (каждое задание на отдельном листе).
- Автоматическая запись данных в Google Таблицы.
- Умная фильтрация: метки «ВРЕМЯ» (опоздание) и «ЧИТОР» (списанный ответ).
- Кэширование имен пользователей для экономии лимитов API.
